二、发现的问题及修复
================================================================================

问题 1: 缺少 requests 依赖
----------------------------------------
严重程度: 高
症状: ModuleNotFoundError: No module named 'requests'
修复: pip install requests flask flask-socketio python-socketio eventlet

问题 2: 临时目录文件被错误扫描
----------------------------------------
严重程度: 中
症状: 数据库中出现 /tmp/xxx 路径的文件
根因: 文件监控未过滤临时目录
修复: 在 file_monitor.py 中添加无效模式列表
新增过滤: __pycache__, node_modules, venv, .git 等

问题 3: 函数体内容提取不完整
----------------------------------------
严重程度: 高
症状: 解析的函数 end_line 等于 start_line，函数体为空
根因: Python使用缩进而非花括号，但解析器使用错误的匹配逻辑
修复: 重写 PythonParser._find_function_end() 方法
使用缩进级别来正确确定函数边界

问题 4: 类方法归属识别错误
----------------------------------------
严重程度: 高
症状: 类方法没有正确设置 type_id
根因: 缩进判断逻辑不正确
修复: 改进 _parse_with_regex() 方法
正确追踪当前类及其缩进级别

问题 5: 函数调用关系解析为0
----------------------------------------
严重程度: 高
症状: 数据库中 calls 表始终为空
根因: 
1. 函数体内容未正确提取，无法解析调用
2. 调用解析逻辑仅查找跨文件调用
修复: 
1. 修复函数体提取逻辑
2. 改进 _resolve_function_calls() 支持同类方法调用
3. 修改 _resolve_all_pending_calls() 支持同文件调用

问题 6: 同文件函数调用未被解析
----------------------------------------
严重程度: 中
症状: 同一个文件中函数的互相调用未被解析
根因: 代码逻辑错误：func_data['file_id'] != file_id
修复: 移除 file_id 不等的限制，允许同文件调用解析
