# Large-Scale Test Project

这是一个用于深度测试代码知识图谱系统的大规模复杂测试项目，包含多种语言的代码库。

## 项目结构

```
large_test_project/
├── python_project/      # Python项目 (复杂模块化架构)
│   ├── core/            # 核心模块
│   ├── api/             # API模块
│   └── cli.py
├── javascript_project/  # JavaScript/Node.js项目 (Express应用)
│   ├── src/
│   │   ├── services/    # 服务层
│   │   ├── routes/      # 路由层
│   │   ├── utils/       # 工具函数
│   │   └── tests/       # 测试文件
│   └── package.json
└── go_project/          # Go项目 (模块化架构)
    ├── internal/
    │   ├── models/      # 模型
    │   └── services/    # 服务
    └── main.go
```

## 功能特性

- 多语言支持 (Python, JavaScript, Go)
- 复杂的模块依赖关系
- 丰富的函数调用
- 完整的业务逻辑
